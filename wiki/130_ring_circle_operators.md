## What was found (`:CALCULATED`, repo's own product)

- **Fifteen circles through e₀.** Every imaginary slot is a circle: L_k² = −I, skew, orthogonal; span(e₀, e_k) is a closed ℂ. Conjugation by any slot-circle rotates every other circle exactly in place by 2θ about its axis, in both bracketings, for all 210 ordered pairs.
- **Adding an axis across a ring is so(n+1).** n mutually anticommuting circle operators close to so(n+1): Lie dimensions 1, 3, 6, 10 for n = 1..4, orbit of e₀ the same. That is the rotation group of Sⁿ. It is not S^(2ⁿ−1): the 15-sphere appears only when all 15 circles act (so(16), 120 dimensions).
- **Two ways two circles meet.** 63 of the 105 pairs anticommute (perpendicular axes); **42 do not**, with anticommutator Frobenius norm 4√2 for every one: they are exactly the 42 Assessor pairs (e_a, e_(b+8)), a ≠ b. The zero-divisor directions among them: 336 directed pairs.
- **Four is where the sedenion deforms.** Circle products of 2 or 3 slots never leave the unit sphere; 210 of the 1,365 four-slot sets do (the first scaling: norm ratio 0.626 … 1.289 outside the octonion). Three slots split into 35 associative lines (6 results over all brackets and orders), 168 (8) and 252 (12).
- **Operator count.** The associative ring generated by the 15 slot-circles is all of M₁₆(ℝ) (256). The **smallest generating set is five circles**; none of four or fewer does, the powers of two {1,2,4,8} give only a 16-dimensional Clifford ring, and 1,008 of the 3,003 five-subsets work.
- **Each prime is a circle.** Slot k ↔ the k-th prime; the Euler factor on σ = ½ is an exact circle (centre 1/(1−1/p), radius p^(−½)/(1−1/p)), turning at ln p = ln 10 · log₁₀ p per unit t.

**Listing 1 — the commutation and generation counts** (written for this page; needs numpy; runs cold in about four minutes)

```python
import numpy as np, itertools
def mul(a, b):
    n = len(a)
    if n == 1: return a * b
    h = n // 2; a1, a2, b1, b2 = a[:h], a[h:], b[:h], b[h:]
    cj = lambda x: np.concatenate([x[:1], -x[1:]])
    return np.concatenate([mul(a1, b1) - mul(cj(b2), a2), mul(b2, a1) + mul(a2, cj(b1))])
N = 16; E = np.eye(N); L = [np.array([mul(E[k], E[j]) for j in range(N)]).T for k in range(N)]
pairs = list(itertools.combinations(range(1, 16), 2))
A = lambda i, j: L[i] @ L[j] + L[j] @ L[i]
print('anticommuting', sum(np.allclose(A(i, j), 0) for i, j in pairs), 'non', sum(not np.allclose(A(i, j), 0) for i, j in pairs))
print('Frobenius norms of the others', {round(np.linalg.norm(A(i, j)), 6) for i, j in pairs if not np.allclose(A(i, j), 0)}, '4sqrt2 =', round(4 * 2 ** .5, 6))
def dim_alg(gens):
    Q = np.zeros((0, N * N)); frontier = [np.eye(N)]; d = 0
    while frontier:
        new = []
        for m in frontier:
            for g in gens:
                p = g @ m; v = p.ravel().copy()
                if d: v -= Q.T @ (Q @ v); v -= Q.T @ (Q @ v)
                nv = np.linalg.norm(v)
                if nv > 1e-8: Q = np.vstack([Q, v / nv]); d += 1; new.append(p)
        frontier = new
    return d
print('all 15 generate dimension', dim_alg(L[1:]))
for k in (4, 5):
    c = sum(dim_alg([L[i] for i in s]) == 256 for s in itertools.combinations(range(1, 16), k)); print(k, '-subsets generating 256:', c)
```
