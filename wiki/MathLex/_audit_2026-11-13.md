`MathLex/` holds 47 concept pages and an index (48 HTML files). Each concept page has a "Jupyter Build" cell: a short Python program followed by an "Out [1]" block. Method: the 46 cells were extracted from the pages (`cayley_dickson_algebra.html` has none) and run (python3, numpy, scipy, sympy), and each printed output was compared with the stated "Out" block.

**Listing 1 — extract and run every cell** (written for this page; python3 standard library plus the libraries the cells import; run from `Ainulindale/wiki/MathLex/`)

```python
import re, html, glob, subprocess, sys
clean = lambda s: html.unescape(re.sub(r'<[^>]+>', '', s))
cells = runs = 0
for f in sorted(glob.glob('*.html')):
    text = open(f, errors='replace').read()
    for cin, cout in re.findall(r'<div class="jupyter-cell">(.*?)<div class="cell-out-label">.*?<div class="cell-out-body">(.*?)</div></div>', text, re.S):
        code = '\n'.join(clean(l) for l in re.findall(r'<span class="code-line">(.*)', cin))
        r = subprocess.run([sys.executable, '-c', code], capture_output=True, text=True, timeout=40)
        cells += 1; runs += r.stdout.strip().split() == clean(cout).strip().split()
print(cells, 'cells;', runs, 'identical to the stated output')
```
